# Steadfast knowledge library

Every coach searches this library first (`knowledge_search` tool → `/api/knowledge`). It is free to
search: no AI call, no paid search API. Web research only runs when the library can't answer.

## Layout
- `library/<department>/<id>.md`: one researched document per file. Departments: physique, nutrition,
  health, appearance, business, wealth, faith, discipline, communication. Expert profiles use `type: expert`.
- `coverage.yaml`: the research plan. Topics without docs show as gaps on the Library screen.
- `index.json`: generated by `node scripts/build-knowledge.mjs` (runs in `npm run build`). Do not edit.

## Document format
Front matter: `id`, `title`, `department`, `topics`, `evidence` (1 strong, 2 moderate, 3 expert opinion,
4 emerging, 5 unsupported/disputed), `agents`, `researched`, `verified`, `review_by` (after this date
it shows as needing re-checking), optional `conflicts`, `status: pending`, `people`, `version`, and
`sources` (each with `title`, `by`, `published`, `url`, `kind`).
Body: `## Summary`, `## Practical application`, `## Limitations` are required; add `## Key findings`,
`## Conflicting evidence`, and for experts the profile sections.

## Rules
- Only claims the cited sources support. Never invent studies, numbers, quotes or Bible verses.
- Original summaries only; no copied books, paid courses or paywalled articles. Link the original.
- Bible quotes only from public-domain translations (World English Bible), verified against the text.
- Health: no doses, schedules or combinations for peptides, hormones or unapproved drugs.
- Adding a document: write the file, add its id to `coverage.yaml`, run `npm run build` (the quality
  gate rejects missing sources, dates, evidence level or required sections). Updating one: edit it,
  bump `version` and `verified`; git keeps the history.
